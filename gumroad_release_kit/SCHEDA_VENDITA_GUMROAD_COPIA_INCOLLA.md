## 🛡️ Come funziona la Verifica Automatica Anti-Frode che ho attivato nel Codice

Nel file [`tpu_security_guard.js`](file:///D:/OneDrive%20-%20ilario/OneDrive/Documenti/GitHub/trading-pro-ultimate/js/tpu_security_guard.js) ho appena attivato la **Verifica Ufficiale API v2 di Gumroad**:
* **Controllo Autenticità:** Quando il cliente inserisce la chiave nella scheda *🛒 Licenza Gumroad*, l'app interroga direttamente i server di Gumroad.
* **Blocco Rimborsi & Abbonamenti Scaduti:** Se un cliente chiede il rimborso su Gumroad o disdice l'abbonamento mensile, l'app legge `refunded: true` / `subscription_ended_at` e **gli blocca immediatamente l'accesso**.
* **Limite Dispositivi Anti-Condivisione:** Ogni License Key Gumroad accetta al massimo **3 attivazioni** (es. PC + iPhone + iPad dello stesso cliente). Se il cliente pubblica la sua chiave online per far entrare altre persone, dal 4° dispositivo l'accesso viene respinto.
* **Vendita Diretta VIP (100% Incasso Tuo senza commissioni Gumroad):** Se un cliente ti paga direttamente (es. Bonifico o PayPal), puoi premere il nuovo tasto **`🔑 Genera License Key VIP Diretta`** dentro il terminale per creargli al volo una chiave `TPU-VIP-2026-XXXX-XXXX` vincolata al suo IP!
